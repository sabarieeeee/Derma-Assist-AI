Derma Assist AI – A Smart Dermatological Tracking & Analysis Web Application

Version Release 2.4.0 — Production Technical Abstract & Project Overview
Development Team: Sabarinath (Developer Lead), Sanjay Krishnan (AI Engineer), Sreyas (Data Analyst), Vinush (Testing & Finance)

Abstract

Derma Assist AI is a responsive, mobile-first dermatological web application designed to deliver real-time, AI-assisted educational insights into skin health using state-of-the-art multimodal vision and conversational artificial intelligence. The system leverages the Groq Multimodal AI Vision Engine running qwen/qwen3.6-27b to perform deep feature analysis on user-uploaded skin imagery. Positioned as an advanced skin-pattern awareness, live clinical consultation, and longitudinal tracking platform, Derma Assist AI enables users to monitor visible skin changes over time with high confidence while prioritizing data privacy through a client-side AES-256 encrypted local storage architecture, strict zero-fallback error guards against false-positive diagnoses, and mandatory authentication security controls.

Project Overview & Core Functionality

The application provides four primary capabilities:

  • Instant Groq AI Vision Telemetry: Users capture or upload skin photos (compressed client-side to <800px for mobile performance). The vision engine validates the image structure and generates structured clinical indicators including primary condition identification, severity level (Mild, Moderate, Severe), confidence scores, observed visual indicators, symptoms, precautions, and actionable step-by-step care plans.
  • Live AI Dermatological Assistant: An interactive, real-time conversational assistant powered by Groq LLM API with condition-specific context binding, streaming typing indicator animations (• • •), and quick-select clinical suggestion pills.
  • Encrypted Patient Health Profile: A comprehensive patient health record module allowing users to record and store encrypted health metrics including Age, Gender, Height, Weight, Skin Type (Normal, Dry, Oily, Combination, Sensitive), Sun Exposure Level, Primary Dermatological Concern, Active Skincare Routine, Known Allergies/Sensitivities, and Emergency Contact details.
  • Longitudinal Progression Mapping: A comparative analytics engine that evaluates visual changes between historical scan checkpoints to track recovery trajectory over time.

Technical Architecture & Analysis Workflow

Derma Assist AI is built using React 18, TypeScript, and the Vite build engine, enabling high-performance, single-page application execution. To guarantee stability across desktop and mobile browsers—including iOS Safari—uploaded images undergo client-side HTML5 Canvas compression to a maximum dimension of 800 pixels before transmission.

The AI analysis pipeline follows a strict, multi-stage execution workflow:

  • Mandatory Authentication Guard: Unauthenticated users requesting a scan are redirected to the secure login/sign-up portal.
  • Quota Management Engine: Enforces a 15-scan daily quota limit for free-tier users, updating dynamically via an interactive hero slider, with native routing to subscription tiers.
  • Multimodal AI Vision Stream: The compressed base64 image string is dispatched to the Groq Qwen Vision API using structured JSON schema constraints (response_format: { type: 'json_object' }).
  • Zero-Fallback Exception Guard: Robust error handling ensures that if an API transport failure, invalid image input, or timeout occurs, the system gracefully alerts the user instead of presenting false/dummy medical reports.

Progression Mapping & Longitudinal Tracking

A key distinguishing feature of the platform is its Progression Mapping module, which enables comparative analysis between two historical scan entries—a baseline checkpoint and a current follow-up scan. The AI algorithm (compareProgression) evaluates visual variations across color saturation, lesion boundary stability, surface hydration, and spatial distribution patterns to determine a clinical progression verdict: Improved, Unchanged, or Requires Medical Attention. The analysis includes a detailed breakdown of observable visual shifts and tailored clinical next-step recommendations to guide the user responsibly.

User Interface Design & Safety Mechanisms

The user interface adopts a premium Liquid Glass Dynamic Effect design system implemented using Tailwind CSS and custom backdrop filters (backdrop-filter: blur(20px) with dynamic diagonal light sheen). The interface features:

  • Mobile Responsive Drawer: A dedicated mobile hamburger menu drawer providing full navigation access (Home, Progression Mapping, Scan History, AI Assistant, Subscription, About Developers) on touch devices.
  • Client-Side Encrypted Storage: All scan archives and patient health profiles are encrypted using AES-256 client-side protocols and stored locally in LocalStorage, ensuring zero third-party cloud exposure of patient photos.
  • Safety Safeguards: Strict medical disclaimers, zero-fallback error guards, and explicit patient privacy indicators reinforce responsible healthcare awareness and prevent misuse.

Key Technical & Functional Specifications

  • Core Technologies: React 18, TypeScript, Vite, Tailwind CSS, Iconify.
  • AI Vision Engine: Groq Multimodal AI Vision Engine running qwen/qwen3.6-27b with structured JSON schema enforcement.
  • Conversational AI: Groq LLM Assistant with real-time context injection and streaming state animation.
  • Security & Privacy: Client-side AES-256 encrypted local storage, mandatory sign-in scan gate, zero external image retention.
  • Performance & Data Handling: Client-side canvas image compression (<800px), 15-scan/day quota manager with interactive slider state.
  • User Experience: Liquid Glass Dynamic Effect design, animated GSAP transitions, responsive mobile menu drawer, patient health profile telemetry.
  • Safety Mechanisms: Zero-fallback error guards, API timeout protection, and explicit clinical educational disclaimers.

Conclusion

Derma Assist AI demonstrates how modern web technologies, client-side encryption, and multimodal computer vision can be integrated into a responsible, user-centric dermatological awareness platform. By combining high-accuracy AI pattern analysis, an interactive live assistant, longitudinal progression tracking, and an ultra-premium Liquid Glass interface, the application empowers users to understand and monitor visible skin health over time while consistently emphasizing the necessity of professional medical consultation for definitive clinical diagnosis.
